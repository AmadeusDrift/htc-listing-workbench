# W14：真实 App 合成规模性能观察

## 范围与复现

对应 `2026-10-13-2.5.0测试与验收标准.md` 第 114 行。基线 `9a4e690`，独立分支 `feat/htc-250-ui-performance`。

运行 `npm run build` 后，用 `node scripts/benchmark-production-ui.mjs` 生成全新 `.test-data/production-ui-scale-*` 数据根并启动本分支 production main / preload / App。复用祖先依赖，无安装或复制依赖，没有 `window.red` 替身。`HTC_PERF_RUN_LABEL` 标记负载环境；可选 `HTC_PERF_PROFILE=1` 仅用于独立根因采样，不将其当无干扰正式计时。

数据为 2000 商品、各 1 SKU / 1 独立 owner 及路径的小 PNG；5000 条合法校验通过的自动任务，每条 1 项，全部 PAUSED；一个暂停、未配置凭据的合成 demo 目标。图片内容是可复用的 1×1 PNG，只有 68 字节，测分页、协议读取和解码流程，不代表真实高清图负载。采集箱每页 20，共 100 页。自动任务选择器保留完整 5000 项，未截断任务或模拟统计。

`launchGuarded` 在主进程入口前阻断 Node/Electron/Chromium 出站。结束检查内存与落盘均 5000 PAUSED、图片执行次数 0；AI / Amazon 调用、FTP 上传、执行任务记录均 0，asset owner / variant owner 全部匹配且外键检查通过。未启动、继续或授予任何任务授权；每轮隔离窗口结束即关闭。合成测试库本地保留，不进版本库。

## 计时方法与真实瓶颈

- `completionWallMs` 从测试动作开始到目标 UI 条件成立，包含 Playwright 定位/等待、IPC、CPU 和本机 IO，不等于用户反馈时间。
- `inputEvents` 从 renderer 的 input/change/click 事件开始，MutationObserver 记录实际输入值、选中导航/筛选、页号或“正在读取已保存任务”的 DOM 反馈。双 requestAnimationFrame 记录反馈后的绘制机会，不声称是屏幕光子级呈现时间。额外记录事件分发延迟。
- `longTasks` 为 renderer PerformanceObserver longtask（标准 50ms 以上连续任务），`processCpu` 为 Electron 各进程累计 CPU 秒数差。CPU 秒并非磁盘耗时；本机 IO 未单独剖析，不能将所有墙钟等待归因于磁盘。
- 初次隐藏窗口出现约 1 秒帧节流，留在 `preflight-hidden-window.json`，不用于 200ms 判断。后续仅对隔离测试窗口调用 `showInactive()` 和 `setBackgroundThrottling(false)`，未激活正式程序；Electron `--force-device-scale-factor=1.25` 不等同 Windows 全局 DPI。

优化前可见窗口预检与其他工作并发，任务切换实际读取提示约 201ms 才进入 DOM，第二帧约 408ms，总完成约 1044ms。renderer 连续任务约 189–227ms，Tab 进程该段累计 CPU 增量约 1.568 秒，Browser 约 0.063 秒。独立 CPU profile 中最高 651 个采样命中 production bundle `index-CDYYhPAv.js` 第 11 行列 44241，代码对应任务选项循环内每项 `new Date(...).toLocaleString('zh-CN',{hour12:false})`。原始 profile 和带采样开销的预检 JSON 保留，不混称安静环境基线。

最小修改：共享显式年月日时分秒的 Intl 格式器，memo 保留任务选项及版本签名；刷新按钮立即显示读取文字并禁用重复刷新，输入与导航仍可使用。没有业务服务改动。日期普通、午夜、跨年、闰日及非法日期显示均与旧实现等价。

## 最终观测与验证

正式安静窗口观测待填；前面的并行预检不能代替最终数值。输出固定在 `artifacts/production-ui-scale/`，包括 report.json、关键截图及独立基线。

已执行日期等价与现有任务分组统计测试 14/14（含日期 7 项）、typecheck/build；Vite 保留已存在的大 bundle 提示。原 `e2e-automatic-listing-ui.mjs` 在旧 start 入参断言处失败：实际已包含 `executionMode: immediate`，该脚本归 core 回归分支维护，本分支未修改其源码。仅在本地临时副本对齐入参后，前两组通过，随后第 144 行展开来源组的 `automatic-result-v-z` 断言未找到元素；已移交 core 分支，不冒充该原脚本整体通过。真实 App 规模脚本有独立的选择、刷新、输入、导航和日期显示语义断言。

边界：单机单轮样本不是 p95 或硬件普适 SLA；本观察覆盖 5000 单项任务记录，不代表单任务 5000 SKU 或真实付费任务运行。未覆盖大审计日志、多兆图片、远端统计、迁移和备份，后者不能凭本结果宣称无阻塞。

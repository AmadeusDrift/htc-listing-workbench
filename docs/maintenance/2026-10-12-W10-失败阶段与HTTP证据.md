- providerError 保留仅 400–599 的真实数字 HTTP 状态，展示明确拒绝 / 结果未知。继续使用原 definitive 白名单，不改变重试上限、预算、结果恢复规则。
- 生图图位错误明确标注 NOT_SENT / DEFINITIVE_FAILURE / RESULT_UNKNOWN；已有状态机、原请求编号、次数及成功图位不变。
- 在生图预处理、请求、响应后核验、预览、候选保存，以及自动任务主循环和后续观察异常映射前，向既有 audit_events 追加 operation.failed 脱敏记录。记录工作流阶段、允许的错误码、关联 UUID、请求结果类别和可识别的相对源码调用位置；不保存错误消息、原始响应体、绝对路径、URL、凭据或任意异常属性。产品级来源/原始调用历史不改写。

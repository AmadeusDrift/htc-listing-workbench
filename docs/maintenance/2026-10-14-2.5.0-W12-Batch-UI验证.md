# 2.5.0 W12 自动准备与真实 Batch UI 验证

日期：2026-10-14。分支 `feat/htc-250-batch-ui`，基础 `f37ae4e`。仅本地提交，未 push、发布、覆盖正式包或操作正式数据库。

## 实现

- 自动准备页新增即时上架 / 延迟批量选择，读取真实 `getAutomaticBatchPlan`。无可 Batch 步骤禁用且说明原因；加载/失败/刷新状态明确。启动将 executionMode 传入原 IPC；原整批确认显示真实任务模式及混合覆盖。
- 覆盖逐用途列出 Batch / 普通执行及主进程原因。生图、Decisions、阿里、DeepSeek 直连使用普通计价；没有全链半价或整任务 24 小时承诺。视觉覆盖不在 renderer 硬改，当前 M09 尚未注入时继续真实 ordinary。
- 任务轮询真实 summary，显示 remote ID、等待/未知/回收/失败、独立远端状态与 locallyStopped、请求数、失败/缺失数、回收未采用数及 SKU 对应关系。展开可见原请求 ID；历史缺映射明确显示未记录。
- 新增窄只读 projection：由 ai_calls 的 draft/variant 身份与任务行匹配 SKU，GET 收据 receivedAt 为最近已收到响应的查询时间；本地 pause/resume 的 updatedAt 不冒充远端查询。没有输出 Batch 请求 body/参考 URL。
- 模式变更仅用既有 setAutomaticExecutionMode，暂停后可切换；原在途/未知批次仍恢复原身份，变更不自动继续。页面明确暂停/取消是本地停止，不提供假远端 cancel。
- 沿用现有主题、控件和分区，新增独立 automatic-batch.css 的响应式覆盖网格。

## 明确边界

- E2E 将来源分类、连接准备状态、托管以及 Batch 之后的图片流程作为测试边界。实际 Batch 结果采用后用下游 sentinel 停止，任务最终 NEEDS_ATTENTION 是测试预期；没有宣称完整图片生成、Amazon 提交或备货完成。
- E2E 不调用真实 AI、Amazon、FTP 或图像服务；真实账号 Batch 权限/价格/时效、在线 M09、正式任务恢复未验。整个仓库全量测试和其他 W12 页面不在此分支验证范围。
- 本分支未改 start/Batch 调度/预算业务逻辑，未发现需要改动的后端集成缺陷。W11 图位 deep link、其他设置与来源页由对应工作包接续。

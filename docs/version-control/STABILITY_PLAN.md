# 稳定化计划与固定回归清单（净化版）

本文件只保留技术结论和实施约束，不包含真实商品、SKU、店铺、任务ID、网络调用记录、凭据或本机目录。完整证据原件保留本地。计划仍待审核，建仓不自动授权实施。

## 三个优先根因

1. 回归基线与真实服务组合缺少一致的验收闭环。先建立问题反例、版本与制品对应关系；不能把局部mock通过等同整个系统可用。
2. 字段目录、事实证据、推断权限和付费请求上下文耦合。元数据变化可能误伤旧图片；证据别名、允许的转换及候选格式需统一。
3. 操作阶段与实际外部请求边界不一致。字段操作STARTED过早，预校验失败也可能阻塞恢复；任务暂停和独立回读调度需要明确协议。

相关位置：src/main/image-workflow/service.ts 的 currentContextMatches/runSeven，src/main/automatic-listing/service.ts 的 finishRepair/pause，src/main/listing-ai/service.ts 的 complete，src/main/listing-ai/semantic-evidence.ts，src/shared/listing-ai-contracts.ts，src/main/ai/service.ts 的 beforeSend，src/main/followup/service.ts 的调度。

## 阶段与验收

| 阶段 | 工作 | 验收 |
|---|---|---|
| A 基线 | 固定源码/规则/环境/夹具；为已知问题写失败测试 | 原代码准确失败于指定原因；排除环境和夹具错误 |
| B 契约 | 局部整理字段能力、证据别名和事实/元数据兼容性 | 元数据更新不伪装事实变化；真实事实变化仍阻断；不覆盖付费历史 |
| C 状态 | 区分未发、已发未知、结果已持久化、待采用；统一暂停边界 | 仅有未发送证据才可安全恢复；未知不重发；重启后权限正确 |
| D 诊断/范围 | 稳定原因码、脱敏关联信息、原任务项白名单 | 白名单外付费/提交为0；图片与身份、父子关系保持 |
| E 回归 | 类型、全量单测、历史回放、服务组合、E2E、隔离制品 | 指定检查无失败/取消；跳过明确补验；制品与源码哈希绑定 |
| F 真实小样本 | 另行批准后进行有界复测 | 新增调用/提交/可售分开统计；效果低时暂停定位，不盲跑整批 |

修复采用局部改动与局部职责重构，保留已有身份账本、图片历史、持久化及未知提交保护。不推倒重写，不放松事实或Schema校验。

## 固定回归清单

以下是待实现/补齐的验收场景，不是全部已经自动化或已经通过的声明。

1. 正常单品完整字段→七图→托管→提交→回读。
2. 同款多色父子顺序及各自来源图片。
3. 来源链接、来源规格、实际执行范围三种数量口径。
4. 售价/ROI边界及不满足时业务跳过。
5. 来源图缺失、错误绑定与兄弟SKU隔离。
6. 真实颜色歧义保持暂缓。
7. Schema固定值原样。
8. 严格枚举合法单值及非法候选拒绝。
9. 开放建议优先真实建议，无合适项使用有依据的准确值。
10. 各字段推断权限、理由与证据一致。
11. 事实别名语义一致，不能借无关证据。
12. 部分候选无效时隔离且保留脱敏拒绝原因。
13. 单位/成分/危险品资料不足时不编造。
14. 品牌审批与程序错误分类不同，不能改品牌规避。
15. 仅字段元数据升级不使旧图片成为颜色变更。
16. 真正颜色、来源字节或身份改变仍拒绝旧结果。
17. 外层字段修复在模型未发送前预校验超时后的恢复。
18. 图片内字段准备在模型未发送前失败后的恢复。
19. 字段已发送未知结果不自动重发。
20. 成功结果已持久化但上层未确认时复用。
21. 生图丢响应，分别检查本地候选有/无。
22. 明确未发送的失败与已发未知分开。
23. 各await处暂停，晚返回不得越权采用或提交。
24. 多商品、多并发、部分失败隔离。
25. 连点/同任务并发/跨任务同SKU重复保护。
26. 正式PUT未知结果跨重启仍不重发。
27. ACCEPTED、ASIN、DISCOVERABLE与BUYABLE分别统计。
28. 原独立销售SKU转父子时身份、图片、历史不变。
29. 原任务项白名单以外新增付费/提交为0。
30. 复核开关及连接generation变化的兼容矩阵。
31. 页面图片与实际SKU/父子关系一致。
32. 保存、崩溃、历史加载及隔离恢复的一致性。
33. 日志归因和环境权限错误可区分。
34. 发布制品哈希及有界真实观察。
35. 暂停任务与独立回读调度的组合和重启行为。

每次修复：先复现→失败测试→最小修改→受影响测试及完整回归。禁止为通过而放松断言或改变业务预期。未覆盖的内容明确标为未验证。

# 2026-10-13 R8：标签按需与上架解耦

## 已确认规则与实现

标签在需要备货或打印时由用户明确准备；自动上架在平台回读 READY 且备货资格通过、批次建立后完成。自动任务不请求标签，也不以标签失败阻止完成；任务暂停、继续、取消不再控制用户独立请求的标签。

- 普通备货保存调用本地 reconcile，正常新标签为 NOT_REQUESTED，缺资料为等待状态；不会排队、授权或发送请求。原有本地数量/身份/演示环境诊断保留。
- 新增 `prepareItemLabels` / `red:item-labels:prepare` / `prepareBatch`，界面提供“准备本批次标签”。仅明确准备或单项/失败重试写入可选 `requestedAt`；严格时间校验且不纳入原指纹，旧备份兼容。
- 已就绪且身份、数量、格式一致的 PDF 直接复用；变化产生新版本，旧版本 STALE 保留，新版本不继承请求意图。PDF 校验、打开、导出快照保护保留。
- 调度、执行入口与发出前均检查请求意图。旧无标记排队/等待记录暂停保留状态和次数；旧在途记录保存完整原行审计后标记 FAILED/INTERRUPTED，只能明确重试。FAILED、未知和耗尽记录不由批量准备偷偷重试；有限自动重试与累计人工重试上限保留。
- 旧 LABELS 错误在重新评估前独立审计保存，再走真实平台回读与备货资格判断。PAUSED/CANCELLED 不观察推进，SCREENED 不重试；回读失败不会直接完成。
- 更新确认框、阶段/完成状态与标签说明。无界面风格重设计。

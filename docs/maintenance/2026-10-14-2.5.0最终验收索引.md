## 实施和接口变化

- OpenRouter 为 GPT / Decisions / 生图入口；旧 OpenAI 官方与生图中转无运行客户端/Key保存/检查/发送入口。保留历史记录、原响应、候选与请求无关 reader，未知旧请求不转换为新网关请求。
- DeepSeek 自有密钥、阿里 OCR/风险接口与 FTP 托管独立保留。18 个用途保存独立模型、真实能力/有效思考、修订和主/疑难目标快照；已有任务不随设置漂移。不同配置实际分组，同配置可合并。
- Batch 真实 POST/GET 协议、remote ID/custom_id、阶段组批、收据与预算持久化；晚到保存与业务采用分离，暂停/本地取消不冒充远端取消。视觉输入经 M09 固定 hash URL 与保留 pin。未支持步骤明确普通调用；无双发切模式，无全链路折扣/完成时限承诺。
- M02 来源主档/版本/事实作用域，M05 Schema预算，M06 原生字段和完整Schema，M07 调用/收据，M08 任务事务端口，M09 图片/托管，M10 采购/标签均保持明确写入者。严格 AST/SQL 库存门禁拒绝未登记写入，不以动态 import 隐藏循环。
- 实际报价资格放在 SKU/草稿，跨启动/付费/发送重核。稳定SKU、人工值、图片版本、逐次费用和 Amazon UNKNOWN 锁保留。普通字段 AI 的既有有界恢复合同与 Amazon/Batch/图片 UNKNOWN 禁重发须区别，不能宣称所有未知类型均可重试或均不可恢复。
- 真实 APP 已接来源采用/事实范围、任务模式与混合覆盖、逐用途模型、实际报价、清理、外观复核、异常定位返回和用途复制；不继续改独立 HTML。

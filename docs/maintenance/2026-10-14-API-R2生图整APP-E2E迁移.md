# API-R2 生图整 APP E2E 迁移

本记录仅合成测试。基线 9a4e690，独立分支 feat/htc-250-image-e2e，复用祖先 node_modules。真实 Electron build、UI、preload、IPC、safeStorage、候选服务；没有替换 window.red，只有主进程传输 fake。没有真实请求、正式库、push 或部署。

## 覆盖与替换理由

- 新活动渠道唯一 OpenRouter，GET images/models/<slug>/endpoints；生图和编辑均 POST /api/v1/images，精确验证 model、provider.only=openai、allow_fallbacks=false、size/quality/background、input_references 和主进程读取的原图字节。
- UI 密钥遮蔽、离页清除；safeStorage 解密验证共享 openrouter.bin 存密钥、openrouter-images.bin 只保存 credentialRef 且 apiKey 为空。留空保存与切换模型/尺寸/质量不改共享凭据；断开后两处删除、重启仍断开。
- 模型 GET 可访问仅是 metadata，不启用生图、不 POST。401/403 安全映射；未保存状态禁止检查；在途检查切页成功/失败及保存失败恢复覆盖。
- revision、重复/外部资产、renderer 文件路径、旧 4K 尺寸与 max/xhigh 质量在发送前拒绝。失败/取消只一次 POST，忙请求拒绝，迟到响应不落盘；源图、商品、草稿、选择不变。
- API-R2 退役原官方/Tyai/Gemini 可激活/多协议 POST、自定义任意模型场景：以 UI 入口不存在、真实 IPC 拒绝旧 provider 的读取/保存/检查/断开、拒绝 Gemini/custom model、旧 vault 不创建替代。没有把旧 endpoint 加进 fake 放行。
- 旧目录同步 15 个任意模型改为 OpenRouter 目录只保留两枚活动 slug，unknown 排除，不切模型或发图。旧候选 provider/model provenance 及 readCandidateFiles / createHistoricalImageReader 对官方、Tyai 和 Gemini 历史仍可读，断开重启也保留。
- 原六种主题/宽度/4.5 对比度与窄窗操作覆盖全部保留。setBackgroundThrottling(false) 使用真实 Electron 方法；原生 capturePage stayHidden/stayAwake 刷新帧后取色，避免隐藏窗口过渡中取色误报；阈值未降低。

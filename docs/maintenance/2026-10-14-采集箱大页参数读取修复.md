# 2026-10-14 采集箱大页参数读取修复

## 根因与修改

100 条/页功能复用了整页参数请求，但 `MiaoshouService.inboxSummaries` 每次最多接受 50 个 ID；原 UI 控件测试只验证 63 行可见，没有验证参数请求结果，漏掉“商品参数读取失败：妙手操作参数无效”。

客户端现在最多 50 条顺序读取，不增加并发、不提高后端上限。每次加载先清空旧参数，所有批次成功后才一次发布该页结果；失败维持错误和重试入口，不显示部分成功与旧页混合数据。Effect 清理后的过期结果不会发布，也不会继续发下一批；切页、卸载和重新读取共用此清理机制。

状态：**现状清单已盘点，未来页面设计待讨论。** 没有修改界面、运行程序或测试，也没有调用真实同步、发布、AI、清理、备份恢复等操作。以下“现有”表示源码可达，不等于实际环境已验证成功；运行中才能确定的布局、焦点、性能和错误均留给后续授权验收。

## 1. 页面总树与计数口径

当前有 **10 个一级入口，设置内 12 个二级分区，手动编辑内 4 个 tab**。折叠区、表格行、动态字段和原生窗口另列，不能都计为独立页面。应用由本地状态切换，没有 URL 路由和完整可恢复的返回上下文。

## 8. UI-G01 全局导航与异常人工处理问答（已确认）

用户已要求继续讨论；本组属于跨页面的架构/交互设计。按用户要求一次呈现整组，不执行重构或测试，不据“继续”推定以下建议获认可。本组只确认共用交互原则，具体页面布局、按钮样式、字段控件和 HTML 预览在后续页面组展示。

1. **导航按什么组织？** 建议按实际工作步骤保留现有十类功能入口，本轮不为每个后端模块新建菜单；AI 仍从设置进入，同时在使用处有定向快捷入口。自动上架负责安排/执行任务，上架进度负责提交后的处理和回读，商品数据负责平台商品/库存/销量；不复制三套任务操作。侧栏分组、顺序及必要的改名后续页面设计具体化。本组不批准增加新业务功能。
2. **查看、处理与返回如何衔接？** 建议查看商品或进入异常编辑不自动移动所属业务分区；“转入手动工作区”等真实移动为独立明确操作。进入处理保留商品、销售 SKU、草稿、原任务/行及问题位置；返回恢复原任务、筛选和展开位置。原草稿不存在时明确说明，不回退另一份草稿冒充目标；只读原问题上下文仍可查看。保留界面位置不承诺恢复过时业务状态，回来读取最新状态。
3. **异常先展示什么？** 建议进入即显示问题摘要：哪个商品/SKU、哪个阶段、原因、受影响字段/词条/图位及可做的下一步；平台原文/错误码可展开。区分待补资料、平台拒绝、系统异常、结果未知，不统一引导用户改文案。平台未指出具体字段则如实标注整条请求/未知位置。问题及解释由业务模块提供，UI 不猜测事实或资格。
4. **怎样找到要改的位置？** 建议“去处理”直达对应 tab/草稿并滚动高亮字段、嵌套行或图位；多个问题用清单逐项定位，未涉及内容保留。高亮具体词语仅在返回证据确能定位时使用，否则定位字段。没有对应编辑项则显示明确原因与合适动作，不打开无关页面；已提交/在途/UNKNOWN 仍按已有业务权限限制编辑，不能用新 UI 绕过。
5. **修改后如何接回任务？** 建议提供“保存并重新检查”；只复核受影响内容及必需依赖，问题的解决由业务检查结果确定。通过后可“返回原任务”，符合原授权/状态条件时提供“返回并继续原任务”；不把普通保存当新发布/恢复命令。需要付费重做时说明受影响步骤，沿用已确认的自动升级/重试与预算，不再逐次索要模型升级确认。失败保留编辑及原上下文；若原任务已取消、版本已变或不允许继续，说明原因而不启动另一任务。单项人工处理不擅自暂停其他可正常处理的 SKU；对当前正在执行项先由既定协调/锁规则判定可编辑性。

## 9. UI-G02 采集箱与商品资料（七点待确认）

1. **列表显示什么、按什么找？** 建议一条商品链接一行，保留待整理/已忽略；优先显示主图、标题/来源、规格数、采购价范围、资料状态/来源更新提示。尺寸重量等详细资料放详情。支持标题、来源链接/编号搜索，并可筛选来源有更新、资料待查看。资料提示由业务结论提供，不能因普通未知或预览失败在 UI 新增上架阻断。
2. **同步进度和失败放哪里？** 建议顶部常驻简明同步条，展示同步中/完成/失败、最近同步时间、新增/更新/失败数及手动同步入口；点详情才看逐商品进度、原因、暂停/继续/重试失败。关闭详情或离页不停止已有同步；未配置时直达妙手连接，认证故障与单商品失败分开反馈。重试按已定失败隔离，不重做已成功项。
3. **商品详情采用什么形式？** 建议由列表打开较宽的侧边详情面板，保留列表位置；需要较多编辑时打开共用完整编辑页，再返回原筛选/滚动位置。内容分商品概况、规格与采购资料、图片、属性与说明、来源记录；默认只读。明确的“编辑资料”进入同一套商品编辑能力，不为采集箱另建一套字段规则，也不自动转入手动分区。小屏适配/实际宽度待预览。
4. **多规格和图片怎样联动？** 建议同一商品里选择规格，联动展示该规格原始名称、采购价/库存、关联图片及适用资料；共用资料单独说明，归属不明保留原文并标明，不硬分给某个颜色。不要求按颜色另建商品。图片预览失败提供重试和打开原商品入口，不自动提前下载全量图片、不生成替代图；缺失关联不拿其他规格图片冒充。
5. **来源新版本怎样查看和采用？** 建议“来源有更新”打开当前采用资料与新来源的差异，突出规格/价格/图片/属性变化；显示当前版本及已有草稿/任务受影响范围。未编辑且未开始处理的自动采用沿用既定规则并留记录；有人工修改或已开始处理的只提示，明确采用后才按规则更新并提示受影响环节。整条链接版本统一，不拆成颜色各自取新版本，不默认覆盖人工值或改写已提交快照；必要冲突显式说明。没有变化时不制造待办。

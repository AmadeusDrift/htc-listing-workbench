# HTC 2.5.0 W03 / U02 事实范围端到端补齐

日期：2026-10-14。分支 `feat/htc-250-fact-scopes`，基线 `f37ae4e`。依据 2.5.0 接口与数据契约、完整方案 W03、验收 U02：逐规格 / 共用 / 未知必须影响实际领域消费；范围与 source/manual/AI 等事实来源、事实确认状态分开。

## 保存、历史与 UI

- 复用 Schema23 的 `product_fact_scopes` JSON 表，数据库仍为 Schema29；没有构造器建表，没有新迁移。
- M02 `products/public.ts` 暴露 `readFactScope`、`saveFactScopes`，由现有 `saveProduct` IPC 白名单进入同一保存事务。范围保存校验商品 revision、事实归属、稳定 variantId；失败整体回滚，不依赖 renderer 标签推断权限。
- 范围修改写 v2 记录，带 scope、可选 variantId、人工范围确认来源、productRevision、confirmedAt，并保留原 sourceReceiptId。原 fact.source/sourceRef/state、妙手原回执与来源快照不因范围确认而改写。原保存审计保留修改前后资料。
- 新 UI 独立 `FactScopeEditor` 接入 ProductEditor；选择“共用”“逐规格 + SKU”“未知”后，通过现有“保存修改”明确确认。`toSaveInput` 保留范围字段；新增事实默认为未知，不默认人工确认事实内容。
- 商品 revision 同事务增加，原 Listing/Image 上下文和草稿继续按既有 revision 校验失效；不覆盖旧结果、不自动续费、提交或发布。背景来源同步看到人工 revision 变化只保留待采用版本，既有冻结不解除。
- 缺 scope 的旧 Fact 保持历史解释，UI 显示“历史未标范围（兼容原解释）”，不后台补造 common；旧客户端遗漏范围字段不会抹掉已保存绑定。已删事实的旧 v1 范围历史保持原兼容，新 v2 严查事实/商品/规格归属和版本。
- 工作区备份恢复保留 v1/v2 范围。便携资料导出含范围时用 JSON v2 和稳定 variantSku，导入映射至新 variantId，避免 unknown 导出后变回全局事实；完全无范围的旧资料仍导出 v1、可读取 v1。

## 实际消费者覆盖

| 消费者 | 范围行为 |
|---|---|
| Listing 完整 Schema / 文案 / sourceAttributes / 字段依据 | 当前 SKU 的 variant + common；unknown 排除。完整 sourceProduct 载荷同步过滤，不通过第二份原始 facts 旁路泄漏别的 SKU。无 scope 的旧完整载荷保持原解释与形状。 |
| Image evidence、尺寸检查、image risk source | 继承同一 Listing 投影；风险资料也按当前 variant 选择事实。旧默认尺寸不变成图片实测依据。 |
| 妙手逐 SKU 尺寸、图片来源测量 | 版本化主档只把人工明确归属的当前事实作为聚合输入；原始通用 attributes/description/detailText 不能再广播覆盖未知范围。原 SKU API 尺寸和选中规格仍保留；无版本化采用/范围记录的旧回执保留兼容解释。 |
| 商品级分类 | 分类仍判断整商品链接。facts 为 common/legacy；variantFacts 带 variantId；unknownFacts 单列并明确“不作为全部 SKU 权威事实”。标题/描述保持原始分类线索，不把逐规格材质改成整商品共同材质。真实离线 keywords 请求验证了此载荷。 |
| 采购币种 / 销售配方 | previewSalesRecipes 按每个来源 SKU 的 current + common 判断币种；不让一个 USD SKU 污染另一个 CNY SKU，也不把未知币种当已确认。原可信 CNY 导入映射仍可独立作为依据。未确认 CNY 的组件不计算人民币成本；稳定来源身份/命名规则未修改，legacy 分支保留原逻辑。 |
| 包装规格 / 件数 / 业务规则 | productSourceQuantity 选择当前 SKU 和共用事实；已进入范围模型的未绑定标题/描述不广播件数。BusinessRules 接收原始范围元数据，防投影移除 unknown 后再次沿用其描述。SKU 明确规格优先、共用实测可参与，旧缺范围解释保留。 |
| 混合配方与声明 | 不将某一个组件的 variant 标量伪装成整套共用事实；共用事实与明确销售配方继续消费。安全声明只评估当前组件事实，不借另一个 SKU 的已确认/冲突事实阻断当前 SKU。 |

行为差异：版本化来源中“包装尺寸 25×15×8、包装毛重 250”若只有未绑定描述，不再作为所有 SKU 的实测。继续使用已确认的 5×5×5 cm / 100 g 业务默认，而非拒绝商品。人工确认为 common 包装长度/宽度/高度/重量后，两个 SKU 的真实草稿都采用 25 cm / 250 g 对应值，原回执保持原文。

# 生图设置在途锁修复

范围：HTC 2.5 API-R2 生图设置。在模型检查未结束时切至其他设置模块，再回到生图页，原 visible effect 会用读取连接的 finally 清除操作 pending，从而提前解锁输入和操作按钮。

修复：分离连接加载 loading 和用户操作 pending，并通过 actionPending ref 防止重复操作与后台读取覆盖在途动作。保留共享连接、服务检查、配置状态和 IPC；无生产请求与数据库迁移。

验证：迁移后的真实 Electron UI/preload/IPC/safeStorage E2E 先复现 key input unexpectedly enabled；修复后完整 `npm run test:e2e:image-generation` exit 0。覆盖检查成功、失败、切页返回、错误后可编辑、保存失败不改凭据、保存成功后跨页默认值一致。`npm run build` exit 0（包含 typecheck）。本地证据 `artifacts/image-generation-e2e-report.json`，light/dark × 1480/1080/760 native capturePage 截图。

对比度调查：首次在隐藏窗口主题过渡前采样得到 1.13；原生截图刷新 compositor 后相同未修改 CSS 满足 4.5:1。脚本先截图再采样，阈值未降低，无样式变更。

仅合成数据与 fake transports，未访问正式库、真实接口、打包交付或 push。E2E 迁移脚本在后续单独提交。

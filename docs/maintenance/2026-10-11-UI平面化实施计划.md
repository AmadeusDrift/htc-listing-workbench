# 工作台平面控件与自动上架整理实施计划

**Goal:** 将用户审核过的平面预览应用到现有 React 工作台，统一 4px 控件，合并自动上架重复商品列表，保留既有业务边界。

**Architecture:** 沿用 React / Electron / 现有 IPC。新增独立平面主题覆盖层，保留现有明暗主题、密度与减弱动效设置。自动上架的选择、原因筛选与商品展开合并为一个组件，选择仅依据当前目标队列的 eligible 信息；历史任务仍由原组件负责。

**Tech Stack:** TypeScript、React、CSS、Node test、Playwright、Electron。

执行方式：本会话串行执行，遵循 writing-plans、executing-plans、karpathy-guidelines、test-driven-development 与 verification-before-completion；用户已经批准在现有工作台实施。

## 验收重点

- 不能通过 UI 把 UNKNOWN 变成普通可重试；不能因同商品某 SKU 异常移除健康规格。
- 搜索和分类影响展示，不静默更改已选商品；说明清晰，选择当前分类与全部商品明确区分。
- 图片、已提交/回读、待补资料、系统待修复与规则淘汰保留不同语义。
- 零业务数据、凭据和运行截图进入 Git。正式安装包另按新源码版本交付流程产生，不把旧 EXE 当作本次改版。

## 第一轮控件落地

| 控件/区域 | 当前设计与行为 |
| --- | --- |
| 主按钮 | 纯色蓝底、4px、32px 最小高度；禁用时灰色，保留明确按钮名称。 |
| 次按钮/危险操作 | 次操作白底细边框；危险操作用红字与红边框，悬停浅红底。 |
| 输入框、下拉、面板 | 统一4px圆角；保留现有键盘焦点、明暗模式及密度偏好。 |
| 动效 | 移除鼠标追光、玻璃高光和按钮悬停上浮；保留120ms颜色变化，遵循减少动态偏好。 |
| 标题与提示 | 压缩标题与留白；错误提示增加红色左边框，商品行直接显示原因与下一步。 |
| 执行设置 | 店铺、图片托管在商品列表之前；全局连接正常时收起，缺配置时展开。 |
| 商品列表 | 8件/页，商品缩略图与来源、规格/可启动SKU数、状态/原因分列；窄窗口按商品纵向排列。 |
| 勾选 | 仅允许选择当前目标下有eligible SKU的商品；全选作用于当前筛选下可启动商品，搜索和分页不清除原选择。 |
| 分类/搜索 | 按商品包含的SKU状态计算分类；关键词匹配标题或当前分类内SKU/规格/安全原因，不显示原始服务报错。 |
| 展开明细 | 展开商品显示销售规格、SKU、状态及原因，保留手动补充入口；UNKNOWN优先显示且不授权重发。 |
| 启动区 | 明示选中商品数与可启动SKU数，禁用时给出原因；沿用原启动范围确认与后台校验。 |

实际页面与新组件截图保存在本地 `artifacts/flat-runtime/`、`artifacts/flat-workbench/`。前者为真实Electron与隔离本地示例；后者为真实React组件、10商品/30SKU合成状态夹具，不代表真实店铺结果。

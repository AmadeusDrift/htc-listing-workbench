# 候选图直接文字内容审核 API（2026-10-15）

本分支仅衔接已存在的 DeepSeek Flash 视觉接口，不修改用途设置、模型能力、迁移或真实配置。

- 新 `reviewGeneratedImageDirect(context, plan, candidate, bytes, fresh, signal?, owner?)` 发送真实候选图片字节，核对 SHA256、尺寸、PNG/JPEG；复用原请求、收据、费用及 durable owner 入口。
- `directImageReviewProfile()` 提供新文字审核 journal/preflight 所需的同一当前配置，只在同步读取用途配置时脱离旧任务 frozen snapshot；发送与记账仍在原任务授权范围。明确要求 deepseek/deepseek-flash、vision/json，无 fallback。原 owner 恢复仍使用原调用配置。
- 新输出显式 `method: candidate-vision/v1`、`ocrResultId: null`，sourceResultIds 仅复制来源依据与 plan。无伪造 OCR、OCR ID 或 PASS。候选/上下文/规划身份、主图无文字、规划文字存在、可见文字证据、尺寸事实继续校验。
- 独立 appearance/IP risk 不在本 API 中代替或跳过。历史 OCR API、输出字符串 OCR ID 与严格旧验证保留，不因删新流程 OCR 步骤清除或解锁旧 UNKNOWN。

验证：先写 4 个合成测试，正常权限确认缺方法的 4 项失败后实现。network guard 下 4/4 通过；追加旧 frozen task/current DeepSeek 路由与 durable owner 测试，修复测试遗漏 import 后单项通过。相关旧 OCR provenance、缺规划文字、逐行引用三项均通过。最后同源 8 项通过见最终分支核验；未运行全量、typecheck/build、Computer Use、真实任务或付费请求。初次受限权限运行因本地回执硬链接受限失败，正常权限守护环境重跑通过，未修改传输保护。

补扫：新 taskBatchPlan coverage 删除独立 aliyun_ocr 项；原历史 coverage reader、OCR call/receipt/计费记录保留。新 direct API 的预算服务明确为 deepseek-chat，无 OCR 前置或付费预留；来源尺寸里已存在 OCR 的引用仍可读，不新增识别请求。新增 coverage 断言留最终集成 BASIC 统一运行，本补提交未重复执行测试。

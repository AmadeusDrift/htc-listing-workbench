# 全工作台去装饰线与 UI 新版打包

用户确认其他 UI 样式，并要求去掉所有与截图同类的装饰线，然后打包。截图标注是样式类型示例，不是仅修改两个位置。

## 改动

- 全局提示、警告、错误、成功消息移除强调侧条，保留文案、图标、状态色与浅底色。
- 手动商品选中、采集箱选中、设置导航、搜索命中规格、自动任务状态卡移除单侧强调线。
- 手动编辑和自动商品分类移除选中下划线，使用浅底色及文字颜色；移除这些页签区域的上下装饰线。
- 规则说明移除左侧强调线。保留正常表格/布局分隔、控件边框、键盘焦点、进度条及链接语义。
- 新增 `启动 HTC UI新版.cmd` 指向独立新包，保留原启动器；新版使用原有本地工作区路径。用户启动前先退出旧程序，避免单实例机制唤起旧窗口。

## 验证与交付

使用真实 React 组件验证明暗主题、三种宽度、无装饰线计算样式、商品选择与筛选。真实 Electron 验证十个工作区；新增断言检查提示和选中态没有强调侧线或下划线。测试使用独立数据和主进程入口前网络拦截。

构建（含TypeScript检查）通过；完整回归2093项：2092通过、0失败、1项因Windows符号链接权限跳过，耗时230秒；真实Electron十页面×两主题×两宽度共40项通过。真实组件六种主题/宽度组合验证无装饰线、分类浅底色与选品行为通过，已目视检查手动与自动页面。对应本地证据为 `artifacts/decoration-regression.tap`、`decoration-runtime.log`、`decoration-ui.log`。

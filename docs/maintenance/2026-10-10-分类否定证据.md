# 分类否定证据与 listing-evidence/v2

分支：`fix/category-negation-evidence`。基线：`b7e2712`（证据契约修复集成）。本记录不授权真实 AI、Amazon、标签请求、push、发布或安装包覆盖。

## 根因与正式 RED

v1 的分类解析继承纯关键词规则：`不适合儿童` 得到 `Child`，`非电动` 得到 `Electric`。若只删掉这些结果，`selectedSkuCategoryAttributes` 又会从 `sourceSpec` 回退到 `originalSpec/normalizedSpec`；`:spec` 的来源选择以 `values.length` 判断存在，可能把真实否定来源当作缺失并放开 infer。确定性映射的 `sourceFactValue` 还会把未翻译原文原样写进开放字符串属性。

首次正式运行 `node --test tests/category-negation-evidence.test.ts`：9 项，2 个既有正控通过、7 个业务断言失败。反例包括错误 Child、错误支持、否定/三岁以上被规范化 Children 覆盖、来源被直接映射、隐藏 age 卡丢失原文，以及 product-level 排除未阻止标题。无 fixture/权限失败。

后续分别先看到 RED 再修复：

- `finite nonnegative modifiers...`：`非常柔软`、`non-slip manual`、显式 `Manual with non-slip handle` 保留原有肯定语义；非年龄角色的 `Non-smokers` 继续使用 v1 原有受众 fallback，避免扩大本轮否定规则。
- `unresolved negative scope...`：多对象及双重否定即使不能解析，也保留相关词项约束，不允许 Child 标题逃逸；无关 `Coaster` 仍通过。
- `comma and slash...`：`不适合儿童/成人`、`not for children/adults`、`not for children, adults` 不把第二项变成 Adult。
- `an explicit affirmative introducer...`：逗号后 `适用成人` / `suitable for adults` 可以有限重启肯定分句。
- `new results stamp v2...` 与 `saved listing-evidence/v2...`：新结果仍 stamp v1、合法 v2 被旧外层白名单拒绝。
- `a bounded exclusion also blocks its named narrower category...`：`非电动` 不支持 `Corded Electric`，`非软毛` 不支持 `Extra Soft`；只传播有限排除，不推导 Manual/Hard 等相反值。
- 独立 SPEC 复审发现 `not electric or corded electric` / `非电动或有线电动`、`not soft or extra soft` / `非软毛或超软毛` 沿用肯定归一后丢失一般词项，导致 `Electric Coaster` / `Soft Bristles` 候选及 current copy 逃逸。读取并运行独立探针后，新增 `unresolved subtype lists retain each separately named category in candidate and current copy constraints` 与 `a subtype token alone never excludes its broader category and clean affirmative normalization stays stable`；正式目标 RED 为 1 fail / 1 pass，失败明确为 unresolved 缺失 Electric。最小修复在负分句独立采集有限字段词项，仅在检查一般词项时遮蔽实际 subtype 出现，保留分别出现的一般词项及 subtype。覆盖中英文、两种列表顺序、candidate/current copy 及无关文案；单独 `not corded electric` / `not extra soft`、中文与双重否定仅 subtype 不排除整个一般类别，无否定肯定归一保持原行为。

## 实现范围

新增冻结的 `evidence-category-v2.ts`、`evidence-contract-v2.ts`、`evidence-validation-v2.ts`，current 入口、context 与 demo 切到 v2。未修改冻结 v0/v1、旧 semantic/colors 实现。

有限解析明确区分来源存在、肯定值、排除值和未解析否定涉及的词项。按角色和有界分句处理；逗号/slash 裸列表不自动清除否定，有限肯定引导词可以重新开始。复杂作用域、双重否定和 `三岁以上` 保持未解析。布尔 false、无味、无香、无蜡，以及有限非否定修饰词保留已有语义。

所选 SKU 首个相关原始来源阻止后续规范化肯定值覆盖。`selectedSkuCategoryAttributes` 只返回确定肯定 canonical 值；context 单独保留相关否定/未解析原文与角色，即使 age 卡隐藏。负来源不解除真实 blocker，兄弟 SKU 和销售配方不替换锚定来源。无关干净 context 不增加 marker，保持顺序、ID、值和哈希。确定性映射保护仅限 age/firmness/power 这些有界角色；未重写其他普通自由文本映射。

当前候选、review、current copy、completion 与图片准入共同使用 v2。只有排除项不能推断相反值，也不能标为 source_absent 开放 infer。明确排除及未解析否定词项阻断对应正向标题；更一般的 product-level 未解析/缺失来源文案义务留给后续独立修复。

## 历史与新产生点

`LISTING_EVIDENCE_CONTRACT_VERSIONS` 固定列出字面量 v1/v2，独立于 CURRENT；测试也使用显式版本字面量。未来增加 CURRENT 不会自动移除 v2 历史。

`stored-evidence.ts` 显式分发无标记 v0、v1、v2。AI 和图片 run 外层允许历史版本并返回保存的原 literal；current 默认始终执行 v2，即使输入无标记或为 v1。新 AI 结果、新 run、新 imageContext 和新 setPlan 均由主进程 stamp v2，模型不能指定。纯 approval reuse 保留原 marker。

独立 SPEC 进一步发现两个当前授权边界并按 RED→GREEN 修复：

- fresh recheck 首次保存从 prior 继承无标记/v1，创建新 context 才更新；早期取消、配置失败会留下错误版本。扩展四项 `a fresh/resumed empty ... recheck versions its new context...`，首次持久化即验证 v2，立即取消零新增调用，然后继续验证合法七图复核与纯复用。新增 `an empty ... run stamps current evidence before a configuration failure` 两版本、`the legacy single-image path stamps a new current context and fresh recheck while preserving the old run`、`single-image record markers preserve explicit historical literals and reject unknown versions`。首次目标运行中七项命中 marker/白名单失败，一项单图 fixture 缺字段补全 transport；限定为预置合法文案无需补全后，该单图真实服务路径单独 RED 明确为 marker=undefined，随后八项目标 GREEN。无 slots 外层也接受显式 v1/v2、保留原 literal，无标记读取不增加属性，拒绝未知版本。旧单图重新创建 current context 时 stamp v2；旧 single run 的三版本 current 否定拒绝仍为零调用。已有 context 的纯恢复/复用不因读取而重标。
- 合成旧 builder 遗漏 selected raw、保留 `normalized_spec=Children Blue` 的隔离生产服务/SQLite fixture：真实来源 `不适合儿童`、age 卡隐藏，旧 caption/setPlan `Child Coaster` 引用旧 `:spec`。恢复当前 builder 后，未标记/v1 的 `old ... captions contradicted by current selected exclusions authorize no images or paid recheck` 两项正式 RED 同时观测 `authorized=true,newCalls=1`，新增的是 mock 文案复核请求，生成仍为七张。共享 current-caption guard 复用现有有限分类排除检查，对历史 expectedText 使用当前来源的 excluded/unresolved 否定词项；不移植历史引用 ID，不把一般未解析/来源缺失当成否定。service 的首次当前授权和 records 的 approved-assets 同用此检查，旧 setPlan、nested setPlan 及已存逐图 plan caption 都进入检查。GREEN 拒绝两种授权，新增复核/生图均为零，原 run 与全部旧 AI `record_json` 不变，历史仍可读。这里是本地 mock 历史，不能当作真实店铺或真实付费历史验收。

最后对 caption 计划选择增加 `current image authorization checks the approved slot plan and preserves superseded rejected captions`。使用合法 `seven-provisional-v1` 详情图协议：第一次带 Child 字幕的计划遇到确定性生成失败，后续无字计划批准同 slot；恢复当前 selected 否定后，扫描所有旧计划会误挡合法当前图，正式 RED 已复现。修复按已验证协议选择各 slot 最后一次尝试（PASSED slot 必须绑定最后 PASSED attempt）及旧单图最后一次计划（完成态 plan/candidate/review 数组对齐）；不扫描已被替代的失败方案。GREEN 中 approved-assets 可用、公共 recheck 完成、生成总数仍为七张，旧失败方案和原 run bytes 保留。最初尝试用主图字幕构造此正控被主图禁字规则拒绝，随后改为上述合法详情图场景才作为业务 RED，未放宽生产规则。

独立 QUALITY 发现候选文本自身带无关否定时的同根因逃逸：来源排除 Child，但 `Child Coaster with no battery` / `Child Coaster, non-electric` / `Child Coaster without batteries` 被解析为 unresolved Child，消费者只取肯定 canonical 值得到空数组；Electric、Soft 及真实 age/power blocker 同样受影响。独立探针先复现 18 fail / 1 pass；正式新增 `unrelated candidate negation never erases source exclusions in candidate/current copy/old caption` 三项、`candidate exclusions and broad terms are not promoted to affirmative or narrower category claims` 正控，以及 `unrelated candidate negation cannot hide real age or power blockers`。正式 RED 为 4 fail / 1 pass。新增共享 `categoryClaimTerms` 只保留候选肯定值和原文实际涉及的 unresolved 词项，用于来源排除交叉检查与 age/power blocker；不把 unresolved 当作肯定支持，不继承来源侧 subtype 排除扩展。`Coaster not for children` 仍不变成 Child 声称；来源仅排除 Extra Soft/Corded Electric 时，宽泛 Soft/Electric 加无关否定不被误提升成更细子类；`Child Coaster; not for children` 的明确肯定部分仍受排除约束。typed 属性支持、source_absent、普通未解析来源文案义务均未扩大，冻结 v0/v1 不变。

QUALITY delta 又发现全文过滤会让不同分句串扰：`Soft Bristles with no battery; not extra soft` 的前句 unresolved Soft 所扩展出的 Extra Soft，被后句真实否定的 Extra Soft 词项错误保留；Electric/Corded Electric 同理。新增 `candidate subtype constraints stay within their own clause: 刷毛硬度/供电方式` 两项三入口正控，以及 `an affirmative or unresolved subtype in its own clause remains constrained despite other negative clauses` 拒绝控制，正式 RED 为 2 fail / 1 pass。最小修复按既有 `categoryClauses` 逐分句解析与词项过滤，再合并；不做全文减 excluded，故真实肯定后再否定、独立分句的 unresolved subtype 仍受来源排除限制，未扩自由文案解析范围。

# HTC 2.5.0 W10 验证记录

日期：2026-10-13。分支：`feat/htc-250-backup`；实施基线：`2c37c2e`（含 W05B）。仅使用本独立工作树的 `.test-data` 合成数据；未访问真实库、真实 AI/Amazon/图床，未部署、未 push、未恢复真实任务。

## 实现

- 新建 `backup-stream.ts`，新备份写 V2，保留原 V1 reader。V2 不再将整个数据库/素材包转 JSON/base64/gzip 或整体 Buffer，不受旧 256 MiB 原始数据/400 MiB 容器门槛限制。旧 V1 reader 原有限额保留，避免兼容格式解压无界。
- V2 header 为 magic、16-byte scrypt salt、16-byte 随机 backup ID；scrypt 参数固定为 N=16384/r=8/p=1/32-byte key。元数据清单自身加密认证；数据按 1 MiB 块串行处理。每块描述符含连续序号、长度、文件索引；nonce 为本备份随机前缀 + 序号，AAD 包含 header、描述符、清单 SHA-256。终止空块必须存在，尾随数据拒绝。每个文件保存字节数、SHA-256、引用角色；当前工程上限是 20,001 个文件/16 MiB 清单，不限制文件总字节数。
- 采用未压缩分块加密，避免整包压缩与内存峰值。导出先写同目录 `.partial-UUID`、fsync，再 exclusive hard-link 发布，绝不覆盖旧备份；正常失败删除本次 partial。硬退出可能留下 partial，未将其当成功备份，也不自动猜测删除。要求目标文件系统支持 hard-link；不支持时安全失败、旧备份保留。
- 恢复先在受控 staging 解密、验序号/认证标签/文件长度/hash/白名单路径、验数据库及完整引用清单，成功后沿用现有恢复日志与回滚切换。预检磁盘可用空间，写盘错误仍按失败处理。source/backup 文件拒绝链接、目录 junction 重定向、nlink != 1 与读取期间身份变化。
- 源图 SHA-256 和 byte_size 现在也与数据库原始记录核对；已批准图片、图片版本、源图证据、PDF、provider receipts 沿原清单纳入。PDF 继续使用既有 32 MiB 格式验证限制，不为大型素材包扩大 PDF 解析上限。
- 保留 W05B `retainBatchHistory` / `pauseBatchHistory` / `retainProviderReceipts` / `indexProviderReceiptPointers`。旧备份恢复在 prepare 与最终 commit 两次合并后续最小身份、UNKNOWN 写锁、费用预算、批次、SKU 命名等。孤立收据指针窗口仍纳入，新备份与恢复后不会自动发送请求。
- 标签 REQUESTING 在备份断连中保留原 id/attempts/requestId，标记 FAILED + REQUEST_UNKNOWN + paused；DOWNLOADING 保持 INTERRUPTED。任何现有 requestPending 等字段不会被清空；W09 的 STALE+pending 构造恢复需整合后共同验证。
- `ReferenceRetention` 新增手动预览→planId/revision 执行，计划仅内存、单次使用，执行先比对内容，再在 SQLite 写锁内重查所有者真实引用与文件身份，检查到 unlink 之间没有 await。默认只清理未引用受控 assets 文件；收据、PDF、历史身份/费用无新 TTL，不自动删除。未配置自动策略返回 automaticEnabled=false。
- 通用保守引用扫描读取权威持久化字段/JSON，不依赖投影。未知/在途平台写、未知补全操作保留草稿、exchange、调用证据；其他完成补全仍使用原 `retireCompletionDrafts` 退休路径。引用 schema 的草稿阻止 schema TTL 删除。未知存在时旧无归属调用事件也保守保留。
- `RetentionOwner` 支持 tables + protects 注入，由 owner 接管自己的表；未注册的表继续保守保护。供 W07 pin owner 接入，避免未整合期间误删。
- 清理已接 `backup-ipc`、preload 和共享 BackupApi。备份和执行清理先拒绝 in-flight，再冻结 automatic/followup/item-label 计时器及采集入口，并在操作期间锁住其他 IPC。释放幂等，只恢复原开关，不调用 start/resume、不赋任务授权、不改变 PAUSED/CANCELLED。服务关闭后不重建计时器。删除原 beforeBackup 对源库的 TTL 清理，避免导出失败前先改变原库。
- SQLite Schema 未加版本，仍由主进程协调 W06/W07 的 27/28。

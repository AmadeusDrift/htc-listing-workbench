## 覆盖与体验路线

10 个一级入口及 12 个设置分区均可切换，使用四个虚构商品、12 个销售 SKU。覆盖自动准备/任务、采集列表/详情、手动资料/规格/图片/字段、上架进度、商品数据、采购单、发货标签、类目索引、操作记录，以及 AI/图片/连接/规则/标签/外观/备份/诊断设置。

首要交互：自动任务 → 蓝色收纳盒“去处理” → 颜色输入 Blue 或采用建议 → 保存并重新检查 → 返回原任务。原错误减少，待继续数增加，其他 SKU 成果保留。未知提交另有核对原请求入口，没有重发操作。

可以体验主题/密度切换、步骤展开、分类计数筛选、商品搜索、侧边详情、大图示意、实际报价明细、未保存提示和若干确认弹窗。顶部“预览导览”说明覆盖范围。

## 明确限制

- 所有商品、价格、使用量、配置及记录均为虚构示例；商品图为明确的线框示意占位，不代表真实商品外观。
- 同步、生成、上传、发布、标签、文件选择/导出、备份、恢复、清理仅显示说明或模拟反馈；没有 fetch、业务 API、真实数据库、真实凭据或业务文件访问。
- v0 以排版和代表性控件为主。部分选择器/设置表单展示结构，尚未实现完整依赖联动、所有筛选、所有字段或真实业务校验；页面有相关说明。普通表单输入不持久化，刷新恢复样本。不要输入真实密钥。
- 颜色字段闭环与少量状态在页面内存中演示；不是可安装的产品，也不是已批准最终界面。
- SKU 模板联动、标签纸条件字段、完整平台 Schema、全部二三级错误状态等继续逐页核对。不做独立试算工具，报价明细在 SKU/草稿中展示。

# R01：完整字段响应兼容与字段局部处理

## 行为

- 完整 schema 继续原样进入提示及 Amazon 验证，新增完整返回示例；不限制为固定字段白名单。
- `nativeValue` 为权威值，系统重新生成展示投影。建议转换枚举大小写归一；不认识的说明记作 `unclassified`，保留 `transformationOriginal`，不作为事实校验依据。
- 单个候选格式/来源引用错误只影响该字段；相同值重复引用合并，不同值重复候选保留冲突及被拒原值，重复说明保留在备注。
- 只转换冻结上下文中精确的当前 SKU ID/编码引用，不模糊匹配其他 SKU。异常引用有当前字段直接来源或当前 SKU specification 引用时沿有效引用继续评估，并保留具体异常 ID 备注；否则仅该字段待补。
- 依赖错误按实际条件字段处理，不删除无关字段；完整 Amazon schema 的 required、条件、枚举、结构及业务值保护保持生效。
- 移除无效候选后，按有效字段和现有属性重新校验；未被 schema、已知 Amazon 修复问题或必填目录要求的 missing 标记 `omitted`，作为说明保存，不触发整单修复。必填问题仍保留字段与原始规则原因。
- 新增元数据为可选字段；旧格式仍可读，已保存的各 item 来源与转换说明保持独立。没有改写原始调用、历史数据库或费用记录。

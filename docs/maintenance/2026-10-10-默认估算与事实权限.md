# 默认估算与商品事实权限隔离（2026-10-10）

分支：`fix/fallback-fact-boundary`。基线：`71814c49cd6a7c78561282964b65e7b8b57644fb`。实现与验证跨至 2026-10-11；本记录不代表真实业务上架验收。

## 根因与范围

旧 Haul 业务规则把缺省品牌、制造商、产地、普通合规声明、尺寸及包装重量写入实际 attributes；现有 sourceMapping 又将任意已填值视为 mapped。旧报价成功分支提前返回，也允许已变化的估价依据继续触发付费工作。保存动作既用于人工编辑，也用于自动执行，不能作为商品事实确认。

本项仅调整现有 Haul businessDefaults 范围。standard、费率/ROI/件数算法、SKU/型号商业标识政策不扩展。保留既有属性、来源、旧业务报告、采纳、图片、付费及提交历史，不按“恰好等于默认数值”删除或迁移。旧设置保留，仅修正解释文案；不增加确认 UI。

## 当前行为

- 缺依据的新品牌/制造商/产地/普通声明及物理参数不再写入实际字段。明确无品牌仍可映射 Generic；缺品牌不能。Imported 仅按当前独立 origin 事实与既有美国站规则派生。商业价格、标价、促销、新品、型号、合法销售件数继续保留。
- `currentFactAuthority` 是当前肯定事实解析器：输入当前销售投影及匹配包装的精确 SKU 回执，先处理冲突，再逐声明/物理分量匹配。来源或人工确认事实可支持，裸值、旧报告和普通 save 事件不可支持。原 selected component 风险 veto 仍独立优先，并保留 `DECLARATION_SOURCE_CONFLICT` 的具体原因。
- 尺寸按现有 Schema 单位和已有 `convertToUnit` 规则比较；原生单位保留精度，真实换单位保留既有 ROUND2。部分字段的真实轴保留事实 ID；缺兄弟轴交 Schema，已填无据轴产生固定 local ERROR、非自动修复的 `FACT_AUTHORITY_REQUIRED` / `FACT_SOURCE_CONFLICT`。depth 单向别名与显式无效/冲突 veto 保留；不扩大词典。
- validate、REUSED、missing-only preview、submit 意图前/发送前与 AI 采纳后的校验共用此权限。旧 mixed partial 值保留，但不因此获得提交权限。现有 UNKNOWN/可变性锁先行，缺依据属于待输入，独立可靠 ROI/IP 仍可淘汰。
- 默认尺寸/重量只补齐私有估价输入。新 `PricingDecision` v2 另存 actual 包装两个 own key 的有界原样 `attributeInputs`：保留缺席/null/partial/native unit/精度/数组顺序；比较仅忽略对象成员顺序。成功 quote 也先验证当前快照。v1 严格 reader 和 literal 历史保持原样，不重算迁移。
- 新付费入口复用同步当前报价检查：Automatic prepare/repair、Listing AI、新 source-color、图片规划/OCR/风险/文字复核以及 generation 意图与发送前。AiService 在原 usage reserve/journal 事务边界之前检查。纯 pricing 变化不拒收已付费响应、不阻止缓存/本地 UNKNOWN candidate 恢复；下一新请求仍被阻断。无效版本或缺 v2 snapshot 失败关闭，合法 standard/v1 不新增定价要求。

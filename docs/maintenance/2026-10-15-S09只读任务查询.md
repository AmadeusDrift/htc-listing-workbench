## 接口与兼容

新增四个白名单查询，shared 类型、main handler、preload 和 API surface 同步；旧完整 list/get 保留兼容，不再用于任务面板轮询。

- `queryAutomaticTaskSummaries({workBatchId?,taskIds?,page,pageSize})`：`pageSize` 严格 20/50/100，taskIds 去重校验。workBatchId 精确读取已存在批次的持久化成员，不能与 taskIds 同传，缺批次不猜当前批次、不新建/适配。任务顺序沿原 Map 倒序插入；页码越界收敛到最后一页。全范围 active 与 lifecycleSignature 包括当前页外任务，普通进度修订不反复触发队列完整检查。
- `queryAutomaticTaskGroups({taskId,revision,search,page,pageSize})`：按原任务首次出现的来源商品顺序分组，搜索完整组后分页；SKU、原规格、父 SKU、原因搜索不受当前页截断。只传当前页轻行，不传完整配方、分类候选、历史或收据。counts 保持原稳定投影口径，尚不声称修复包装/利润分类。
- `getAutomaticTaskItem({taskId,revision,itemKey})`：精确原任务/版本/行，只 clone 单条完整记录。
- `queryAutomaticResumeItems({taskId,revision,page,pageSize})`：只返回 key/sku/stage/draftId，跨页选择保留；原 preview/confirm 仍由 owner 全量校验和 CAS。

三种任务范围查询版本不符返回 `{kind:'revision-conflict',taskId,revision}`，不回退另一任务。UI 对任务、页、搜索、修订变化作过期保护，跨 effect 的在途观察串行；活跃10秒/空闲30秒，隐藏暂停。AutomaticPage 的队列读取同样串行并丢弃过期返回。完整图位/报价、历史和原分类详情按 SKU 展开读取；完整来源检查仍为显式按钮。

无迁移、无新持久化业务字段、无写 SQL、无预算/请求身份/费用/成功图片/Schema/报价资格变更。回退程序代码不丢业务历史；旧 list/get 合同未删除。纯状态函数从 renderer 移到 shared 供两端共用，保持本轮前半原行为。

## 根因与 RED

相关来源实际存在时，typed 属性已经要求来源支持，但自由文案仍有缺口。例如来源 `适用年龄=三岁以上`，`Adult Cleaner` 仅引用材质，冻结 v0/v1/v2 的候选、审核与图片文案路径都可能接受。v2 只处理有限排除及未解析否定约束，普通未解析肯定来源和非 selected 的正向不匹配尚未要求真实支持。

首次正式运行 `tests/prose-evidence-boundary.test.ts`：13 项，12 个业务断言失败、1 个 source_absent 既有边界正控通过。覆盖四文案字段、明确负向声明、有限非声明短语、blocker、拆分审核声明、旧版本、图片文案、自动修复和 adoption 责任。

后续独立目标 RED 与最小修复：

- 当前图片文案复核在发现 `三岁以上` 无法支持 Adult 前已经发起请求：1 fail（新增调用为 1，预期 0）。把当前来源与 adoption 检查放到付费入口前。
- 坏 adoption proof 或无类别词的材质错误被标成 citation，进入同值修复授权：1 fail。完整当前诊断与有限类别修复资格分开；缺结果、坏 hash、缺候选、候选值不符仍阻断当前使用，但不授予本轮同值修复权限。
- 同 scope 中一条真实 Adult 来源与另一条 Child 排除并存时，排除行不能充当 Adult 的支持引用；stored context 缺年龄行不能掩盖当前新增相关来源的原 ID 引用义务：2 fail。肯定引用只接受真实含该肯定值的有效来源；stored 完整证据检查之外独立执行 current 有限类别检查，不补造或重绑 ID。

图片旧 builder 测试最初使用 `assert.rejects` 直接接同步抛错，属于测试断言包装错误；七图同值正控最初缺演示 schema 必填字段、或由 stub completion 留下 ACTIVE 操作，属于 fixture 设置错误。另有新测试的 TypeScript 返回值类型和 nullable 断言错误。以上均已修正，不计为业务 RED；没有降低生产断言。

## 实现边界

新增冻结的 `evidence-prose-v3.ts`、`evidence-contract-v3.ts`、`evidence-validation-v3.ts`。当前入口使用 v3；v0/v1/v2 及其 parser、semantic、color 依赖均未修改。typed infer、typed 解析和原有普通类别推断权限保持原规则。

有限文案识别只覆盖 `item_name`、`bullet_point`、`product_description`、`generic_keyword`，以及使用同一规则的图片 `expectedText`。英文整词包括 Adult/Child/Children/Kid/Toddler/Baby/Infant、Manual/Hand Powered/Electric/Corded Electric/Battery Powered；firmness 限明确 Soft/Extra Soft/Medium/Hard/Firm 与 bristle/bristled/toothbrush 相邻语境。不是任意 NLP、任意数值年龄或通用配件校验。

仅文案提取遮蔽有限非声明短语：baby blue、baby shower、adult supervision、instruction/user/owner manual、manual instructions。遮蔽保留原位置，同句其余真实年龄或动力声明仍检查；颜色证据规则仍独立执行。hard surface、soft touch 继续通过。

复用冻结 v2 的分句和来源极性规则，来源优先级继续由 selected SKU / 销售投影决定。相关来源存在但未解析、冲突、仅排除而没有所需肯定支持、值不匹配或真实 blocker 均拒绝。存在相关年龄来源时，明确 `Not for children` 只接受显式 Child 排除和它自己的原始引用；Adult 不能推导 Child 排除，Child 排除也不能推导 Adult。复杂否定作用域保守拒绝，不把无关否定清空后的文本当作支持，也不继承来源侧 subtype 扩展来新增候选词。

候选、整体审核 check、每个拆分 claim 都保持各自的引用义务。拆分审核从全文出现位置继承极性和非声明语境：`Not for children` 的 `children` 不重解释成肯定；`Baby Blue` 的 `Baby` 不重解释成年龄；`Adult Manual Cleaner` 的 Adult 和 Manual 子声明分别只需对应来源，整体仍须完整通过。

source_absent 普通文案（包括既有负向文案）保留既有义务。本轮没有新增 prose infer、没有 typed→prose 派生事实授权、没有伪造 inferenceReason，也没有把 source_absent 普通手工文案全部禁用。因此不能宣称所有有限类别声明已全面证据化，也不能把上述负向来源义务理解为全面 source_absent 禁令。

## 自动修复与同值采用

有限 source/citation issues 在 `AMAZON_VALIDATED` 提前返回之前进入既有字段裁剪。只修复被报告的文案字段，其他手工字段保留；继续使用原 partial 响应、2+2 预算、freshness、review/adopt、remaining 与 UNKNOWN/取消规则。没有把所有 current 诊断字符串转换成覆盖许可。

四文案字段按已验证、修订递增的 adoption 顺序，选最后一个 `after === 当前值` 的责任记录，然后严格验证结果、context/hash、候选存在和候选值绑定。坏最新记录不能退回旧好记录；较新的不匹配记录不能遮蔽更旧但匹配当前手工回退值的责任。typed 字段保留原遍历方式，历史不改写。

只有当前 round 明确记录的有限类别 citation 失败，且新候选完整通过时，才允许同值新增 revision/adoption；普通同值继续跳过。材质/颜色/数值等其他错误和坏 proof 不通过新 helper 取得同值修复权限。DONE 只计算当前 remaining，零调用、零 preview，journal JSON 不改。

真实同值用例：合法来源 Adult，v2 旧 `Adult Cleaner` 候选只引 material；新 v3 候选保持文字、改为实际 age 引用。complete 仅请求该字段，两次模拟调用后新增一条 adoption，旧结果与旧 adoption 不变。随后真实加密备份和恢复均通过严格 stored 历史校验；在恢复目录新建 WorkspaceStore、AmazonService、HostingService、AiService、ListingAiService 及独立 SQLite 连接，确认两条 adoption 保留、当前快照通过、DONE 零调用且 journal 不变。这不是仅重建协调器的“重启”声明。

## SPEC delta：重复词的否定作用域

独立 SPEC 发现来源排除 Child 时，`Not for children and suitable for children`、`Not for children but child friendly`、`Not for children, children welcome` 被接受。冻结 parser 的类别集合去重后只有 Child，v3 先前把整句 excluded Child 分配给每个出现位置，后一个肯定词也变成否定。来源自身使用同样混合句时，也可能给简单 `Not for children` 提供错误的负向支持。

正式新增 6 项，目标 RED 为 5 fail / 1 pass：candidate、current copy、split review、caption 四入口及来源侧反例失败，单一排除/清楚分句/source_absent 正控通过。四入口均循环覆盖四 prose 字段，并扩展 Electric/Corded Electric、Soft Bristles、Hard/Firm Bristles 的同根因；source 反例包含 `不适合儿童且适合儿童`、中文动力/刷毛重复以及英文同义词。

最小修复只在 `evidence-prose-v3.ts`：有排除的分句出现多个有限声明词时，保持未解析，不把首个操作符授予所有重复出现。即使 `Not for children or kids` 的两词可能都受否定，也要求明确分句，而不猜测 conjunction 作用域。source 侧额外按现有中英文有限类别词检查同一分句的重复作用域，子类短语整体匹配；没有重写 v2，也没有通用 conjunction/NLP 规则。明确分号及既定逗号肯定引导分句仍独立处理，`Not for children; suitable for adults` 保持合法；单独 Corded Electric/Extra Soft 不因包含宽词而被误计两次。source_absent 在读取这些结果前继续按旧规则退出。

## QUALITY delta：非刷毛词不能转移否定

独立 QUALITY 发现 `刷毛硬度=非软毛` 时，`Not soft handle but soft bristles` 被错误接受。原因是 polarity 使用整个分句的 parser 词项，但此前 mixed-scope 检查只计相邻 bristles 的声明；前一个不描述刷毛的 Soft 消耗了否定，后一个真正的刷毛声明继承了该否定。Firm Grip/Firm Bristles、Extra Soft Handle/Extra Soft Bristles 同根因。

正式新增 5 项，目标 RED 为 4 fail / 1 pass：四 prose × candidate/current copy/split review/caption 的混合句反例失败，普通形容词/分句正控通过。最小 v3 修复复用已有有限 parser 词项的 mixed-scope 检查：否定分句中非 bristle 形容词也计入作用域歧义，但只有实际匹配到 bounded bristle 声明才执行其来源支持检查。不扩展为普通 Soft/Hard 文案的属性声明识别，不改 v2，不做 conjunction NLP。

正式正控保留 `For hard surfaces`、`Soft touch handle`、`Not soft handle`，以及硬毛来源支持 `Soft touch handle with hard bristles`。`Not soft bristles` 仍可由真实排除支持；分号明确分开时各分句独立判断，软毛来源支持 `Not soft handle; soft bristles`，排除软毛的来源则拒绝它。source_absent 原规则和 literal v2 原语义仍保留。

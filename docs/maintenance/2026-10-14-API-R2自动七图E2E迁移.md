# API-R2 自动七图 E2E 迁移

范围：scripts/e2e-automatic-images.mjs 测试层。真实独立 Electron、preload/IPC、safeStorage、商品与图片服务、fake 文案/生图/阿里传输；不改 window.red，不调用正式接口、不读写正式库、不安装依赖、不发布。

## 原夹具失配与等价覆盖

- 官方/Tyai 生图端点替换为唯一 OpenRouter /api/v1/images，精确检验 openai/gpt-image-2.5-sunburst、provider.only/openai、allow_fallbacks=false 与 input_references 字节；旧端点无法被 fake 接受。
- API-R2 用途不再靠旧角色配置隐式迁移。用真实 saveAiPurposeProfile 明确配置此套既有 DeepSeek 文案夹具，保留独立用途快照与真实服务链。
- 当前默认外观复核加入 fake schema 响应；严格校验每张原图与最后候选图的哈希、请求模型和七图阶段顺序，不关闭新复核。
- 视觉摘要 fixture 不以标点承担语义。全文进入生图 prompt 的断言不变；来源不清当前安全提示和持久化原始不确定原因均检查。
- 风险说明检查真实 high 等级、90/high 当前阈值和 trademark 标记，并额外检查原始品牌标识描述仍在结果中。独立开关完整返回值包含 scoreThreshold/levelThreshold，不删字段求绿。
- URL-only 来源 fixture 通过实际 prepareSourceConsistency 观察，不用人工确认，不手工绑定原图；fake 只返回原图观察且核验全部引用字节。自动下载只绑定请求的 SKU，同时断言原回执同图兄弟SKU映射不变。
- 备份迁入当前 HTC-BACKUP-2，使用生产 authenticated streaming reader 校验每个文件哈希。已付费候选/回执属于应保留历史；逐字节对比候选，所有备份文件扫描 fake keys，仍禁止 vault/browser。
- 隐藏窗口改用 setBackgroundThrottling(false)；native capturePage stayHidden/stayAwake 截图独立超时，截图问题不覆盖原失败与退出码。

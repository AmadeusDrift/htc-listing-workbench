# UI 平面控件与自动上架预览 v1

## 范围

- 用户要求直接制作完整 HTML 预览；控件统一 4px 圆角、平面样式，轻微反馈动效；自动上架须有多个商品示例。
- 新增 `docs/ui-preview/index.html`：独立、无依赖、可离线打开的设计预览。10 个业务导航页面和控件规范页；自动上架为主要详设页面，其他页面提供布局示例，尚不代表完整业务功能规格。
- 自动上架包括 8 件模拟商品、20 个销售 SKU；支持筛选、搜索、展开、批量选择、详情抽屉、范围确认和模拟暂停。来源、商品、图片、店铺及连接状态均为模拟数据；缩略图为内嵌 SVG 示意。
- UNKNOWN 单独呈现，只有核对入口；已完成结果保留、SKU 独立处理等语义在页面中说明。
- 原 renderer、业务状态、IPC、数据库和安装包未改动。这是待用户审核的设计方案，并未获得正式 UI 实施批准。

## 打开

- 直接用浏览器打开 `docs/ui-preview/index.html`。
- 或从仓库运行 `node docs/ui-preview/serve.mjs`，打开 `http://127.0.0.1:4179`。仅监听本机回环地址，提供该 HTML，不提供目录或业务接口。

## 预览限制

- 启动、保存规则、连接检查、添加商品等提供明确的模拟反馈，不持久化或执行实际任务；模拟暂停保留在当前页面会话。
- 待上架与已提交完成分类按 SKU 状态聚合，一件混合状态商品可能同时属于多个分类；这些分类数量不能相加当作总商品数。
- 正式实施前需审核控件尺寸、密度、分区、错误提示以及各业务页面细节，再逐步映射到现有业务契约。

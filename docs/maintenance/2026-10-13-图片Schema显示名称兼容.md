# 2026-10-13 图片工作流 Schema 显示名称兼容（R4）

## 根因及修复

晚间实跑 69 的旧图片上下文与当前 Schema 缓存版本相同，差异仅为 item_type_keyword 的 anyOf 枚举显示名称（Patio 面包屑改为 Home & Kitchen）。枚举值和规则未变。字段流程已有 sameSchemaValidation 兼容，图片流程却仅比较 checksum/正文 hash，误报商品或来源图片变化。

图片七图流程及旧单图复核的 freshness 检查复用 sameSchemaValidation：原 checksum、版本和正文 hash 全同直接通过；否则只在版本相同且冻结 fullSchema 的实际校验内容相同时通过。没有冻结 fullSchema 时不放宽。该比较只忽略配对有效的 enumNames 注解，仍严格比较元 Schema、规则及数据字面量。

不写回旧草稿 Schema，不替换图片上下文，不重算旧依据 hash。真正的枚举值、必填项、字段说明、元 Schema 或版本变化仍 BLOCKED，提示“Amazon 字段规则已更新，当前图片依据与新 Schema 不兼容，请重新核对字段规则”。自动任务现有分类以证据为准、默认 SYSTEM_REPAIR/SYSTEM_FAILURE；本修复没有引入来源缺失类别。
